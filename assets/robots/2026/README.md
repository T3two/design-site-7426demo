# RICOCHET CAD image gallery

This folder holds exported CAD screenshots from the team's 2026 RICOCHET technical binder.

The website's 2026 page automatically shows a gallery once `robot-overview.jpg` is present. The gallery is already implemented and is not published if this image is missing.

The remaining JPEG filenames used by the gallery are:

- robot-overview.jpg
- intake.jpg
- hopper.jpg
- feeder.jpg
- turret.jpg
- scoring-assembly.jpg
- climber.jpg
- robot-positions.jpg
- scoring-iterations.jpg
- intake-iterations.jpg
- post-arizona.jpg

An additional `drivetrain.jpg` is included in the photo package; the page currently displays a higher-resolution drivetrain render already stored at `assets/document-image-12.png`.

The original cropped JPEGs are provided in the `ricochet-2026-binder-gallery.zip` downloadable artifact. Preserve names and push the image files into this folder. The page code needs no subsequent edits. These are real screenshots from the team's uploaded technical binder, not generated illustrations.
