# CAD Library

Browse interactive CAD models of individual parts and complete assemblies.

## Individual parts

Add individual part models to `models/parts/`.

## Assemblies

Add complete assembly models to `models/assemblies/`.

## Add a model

1. Export your Onshape model as **GLB**.
2. Upload the `.glb` file into the correct folder in this repository.
3. Open `models/catalog.json` and add an entry using the example format.
4. Commit your changes. The model will appear in this library.

For manufacturing or further CAD editing, provide a STEP file or a link to the original Onshape document as well. GLB is intended for browser viewing.
